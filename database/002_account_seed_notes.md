# 账号初始化说明

当前部署已经创建第一个管理员账号（工号 `T2026-0001`）。下面保留初始化规则，供新环境部署时参考。

新环境首次部署采用以下初始化流程：

1. 首次打开初始化页面；
2. 输入管理员姓名、登录密码；
3. 系统从 `xt_number_sequences` 取当年 `staff` 序号，生成工号，例如 `T2026-0001`；
4. 写入 `xt_accounts`，`role='admin'`、`number_type='staff'`、`must_change_password=1`；
5. 后续学徒账号由管理员创建，系统生成学号，例如 `S2026-0001`；
6. 所有新建账号首次登录必须修改密码。

编号规则：

```text
学徒：S{年份}-{4位序号}
管理员/教职工：T{年份}-{4位序号}
```

分配编号必须在事务中完成，使用 `SELECT ... FOR UPDATE` 锁定对应年份和类型的 `xt_number_sequences` 行，避免并发注册得到重复编号。
