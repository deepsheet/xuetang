深表学堂考勤系统 · 转发运行说明
================================

一、运行环境

1. Windows 10/11 64 位。
2. MySQL 8.4 LTS（或 8.0）已安装并运行，默认端口 3306。
   MySQL 下载地址：https://dev.mysql.com/downloads/mysql/
3. 完整运行包已包含 Node.js 运行时和依赖，不需要另外安装 Node。

二、第一次使用

第 1 步：安装并启动 MySQL

确认 Windows 服务中的 MySQL84（或 MySQL80）正在运行。

第 2 步：初始化数据库

双击：setup-database.bat

按提示输入 MySQL 的 root 密码。脚本会：
- 创建数据库 xueting；
- 创建网站专用账号 attendance_app；
- 执行表结构迁移；
- 写入 config\database.env。

完成后请保存屏幕上显示的应用账号密码。该密码也会写入
config\database.env，请不要把该文件发给无关人员。

第 3 步：启动网站

双击：start.bat

浏览器会自动打开：
http://localhost:8080

首次打开没有管理员账号，页面会显示“初始化管理员”。
填写管理员姓名和密码后，系统会自动分配工号，例如 T2026-0001。

第 4 步：创建学徒账号

管理员登录后进入后台：
http://localhost:8080/admin

在“账号管理”中注册学徒，系统会自动分配学号，例如 S2026-0001。
把学号和初始密码交给学徒，对方首次登录时需要修改密码。

三、常用操作

- 学徒端：签到、签退、查看在校时长、接收和完成任务。
- 管理后台：账号管理、考勤记录、在校时长、任务管理、审计日志。
- 数据备份：使用 mysqldump 备份 xueting 数据库。
- 修改配置：config\database.env。

四、注意事项

- 不要直接双击 public\index.html，必须通过 start.bat 启动，
  否则登录、MySQL 和浏览器定位可能无法正常工作。
- 默认只监听 localhost:8080。局域网/公网多设备访问需要 HTTPS 和
  服务器部署，不要直接把 MySQL 3306 暴露到公网。
- 如果 8080 被占用，可以在命令行执行：
  set PORT=8081
  start.bat
- 如果 MySQL 未安装，setup-database.bat 会给出提示。
- 本压缩包不包含当前开发机器上的任何数据库密码或 root 密钥。

五、目录说明

public\        前端页面和样式
server\        Node 后端
database\      MySQL 表结构迁移
config\        数据库连接配置
runtime\       完整运行包内置的 Node 运行时
start.bat      启动网站
setup-database.bat  初始化 MySQL 数据库
README.md      完整技术说明
